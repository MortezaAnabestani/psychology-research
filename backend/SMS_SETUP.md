# راهنمای راه‌اندازی سیستم ارسال پیامک با کاوه‌نگار

## مراحل راه‌اندازی

### 1. ثبت‌نام در کاوه‌نگار
1. به سایت [Kavenegar.com](https://panel.kavenegar.com) مراجعه کنید
2. ثبت‌نام کنید و وارد پنل کاربری شوید

### 2. دریافت API Key
1. در پنل کاوه‌نگار به بخش **تنظیمات** بروید
2. **API Key** خود را کپی کنید

### 3. تنظیم متغیرهای محیطی
در فایل `.env` متغیرهای زیر را اضافه کنید:

```env
KAVENEGAR_API_KEY=your-api-key-here
KAVENEGAR_SENDER=10008663
```

**نکته مهم:** اگر خط خاص دارید، `KAVENEGAR_SENDER` را با شماره خط خود جایگزین کنید.

### 4. نصب پکیج (قبلاً انجام شده)
```bash
npm install kavenegar
```

## نحوه کار سیستم

### زمان‌بندی ارسال پیامک
سیستم به صورت **خودکار** در زمان‌های تعیین شده توسط مخاطب، پیامک یادآوری ارسال می‌کند:

1. **Cron Job** هر دقیقه اجرا می‌شود
2. چک می‌کند که آیا notification برنامه‌ریزی شده‌ای برای 5 دقیقه آینده وجود دارد
3. برای هر notification:
   - **Push Notification** به مرورگر ارسال می‌شود
   - **Email** به ایمیل کاربر ارسال می‌شود
   - **SMS** به شماره موبایل کاربر ارسال می‌شود

### محتوای پیامک
پیامک شامل موارد زیر است:
- پیام انگیزشی متناسب با تمرین
- دعوت به انجام تمرین
- امضای "پژوهش روانشناسی"

مثال:
```
وقت انجام تمرین روزانه شماست! امروز چه لحظه خوبی را تجربه کردید؟

برای انجام تمرین وارد پنل شوید.
پژوهش روانشناسی
```

### شرایط ارسال پیامک
پیامک فقط زمانی ارسال می‌شود که:
- ✅ کاربر **شماره موبایل** وارد کرده باشد
- ✅ **API Key** کاوه‌نگار تنظیم شده باشد
- ✅ notification برای زمان مشخص برنامه‌ریزی شده باشد

### فرمت شماره موبایل
- شماره‌های ایرانی به صورت خودکار به فرمت بین‌المللی تبدیل می‌شوند
- مثال: `09123456789` → `989123456789`

## تست سیستم

### تست دستی
می‌توانید از این کد برای تست استفاده کنید:

```typescript
import { SMSService } from "./services/smsService";

// تست ارسال پیامک ساده
await SMSService.sendSMS("09123456789", "این یک پیام تستی است");

// تست ارسال با قالب
await SMSService.sendTemplateSMS(
  "09123456789",
  "template-name",
  {
    token: "مقدار اول",
    token2: "مقدار دوم"
  }
);
```

## رفع مشکلات رایج

### پیامک ارسال نمی‌شود
1. **چک کنید API Key صحیح است**
   - در فایل `.env` مقدار `KAVENEGAR_API_KEY` را بررسی کنید

2. **چک کنید کاربر شماره موبایل دارد**
   - در پنل ادمین یا تنظیمات کاربر شماره موبایل را بررسی کنید

3. **چک کنید موجودی حساب کاوه‌نگار کافی است**
   - وارد پنل کاوه‌نگار شوید و موجودی را چک کنید

4. **لاگ‌ها را بررسی کنید**
   - در console سرور پیام‌های خطا را بررسی کنید

### خطای "KAVENEGAR_API_KEY is not configured"
- فایل `.env` را چک کنید
- سرور را restart کنید تا متغیرهای محیطی بارگذاری شوند

## محدودیت‌ها
- کاوه‌نگار محدودیت تعداد ارسال در ساعت دارد
- برای ارسال انبوه، از قالب‌های پیش‌ساخته کاوه‌نگار استفاده کنید

## هزینه‌ها
- هزینه هر پیامک بستگی به تعرفه کاوه‌نگار دارد
- معمولاً هر پیامک حدود 50-100 تومان است
- برای پیامک‌های انبوه تخفیف وجود دارد
